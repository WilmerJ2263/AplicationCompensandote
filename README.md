COMPENSANDOTE – Family Compensation Fund

Description:
This project is a Python application developed with Tkinter. It allows users to register affiliates, calculate membership fees, view records, generate reports, and delete information.

Main Features:
Login with a password.
Affiliate registration.
Membership fee calculation according to income and employment type.
Selection of additional services.
Display of registered affiliates in a table.
Generation of reports.
Deletion of affiliate records.

Data Structures:
The program uses three data structures:
Stack: Uses a list and follows the LIFO principle.
Queue: Uses deque and follows the FIFO principle.
List: Uses a list to store and manage records.

Requirements:
Python 3
Tkinter
Collections
Datetime

How to Run:
Install Python 3.
Save the program as a .py file.
Open the terminal in the folder where the file is located.

Run the following command:
python filename.py
